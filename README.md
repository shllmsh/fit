# Забей ковёр

Интерактивный сайт по макету презентации. Экраны сохраняют исходные пропорции и целиком помещаются в доступную область дисплея. Прокрутка, автоперелистывание и переключение стрелками клавиатуры отсутствуют. Навигация работает через кнопки макета и правую область экрана в последовательных ветках. «Назад» учитывает фактический путь, в том числе после обновления страницы. QR-коды и телефон кликабельны.

## Разработка

Node.js 20.19+ или 22.12+; в облачной среде проверен Node.js 24.19.0.

```sh
cd /workspace/fit
npm ci --cache /tmp/fit-npm-cache --no-audit --no-fund
npm run dev -- --port 4173 --strictPort
```

## Проверки и сборка

```sh
npm run build
npm test
```

Браузерные тесты выполняются против запущенного сервера на порту 4173. Им нужны Python, Playwright, Pillow и Chromium; они уже доступны в этой облачной среде. При необходимости адрес сервера задаётся через `FIT_TEST_URL`, путь к Chromium — через `FIT_BROWSER_PATH`. Проверяются все 25 экранов на четырёх размерах дисплея, их достижимость кнопками с главной, переходы и возвраты, история, обновление страницы, управление клавиатурой, касания, контактные ссылки и совпадение изображения макета.

Для проверки production-сборки:

```sh
npm run preview -- --port 4174 --strictPort
FIT_TEST_URL=http://127.0.0.1:4174 npm test
```

Содержимое `dist/` — статический сайт; сервер и секреты приложению не нужны.

## Просмотр без установки программ

Для автономного просмотра можно собрать один HTML-файл, в который включены все экраны, стили и кнопки:

```sh
npm run build
python scripts/build_offline.py /workspace/zabey-kover-preview.html
```

Скачайте этот файл и откройте его в браузере на компьютере двойным щелчком. Веб-сервер и Интернет для экранов и переходов не нужны; Интернет нужен только для внешних контактных ссылок. Встроенный предпросмотр в интерфейсе настройки облачной среды не поддерживается.

## Макет

Изображения `public/screens/8.webp` — `32.webp` получены из утверждённого файла `ЗАБЕЙ КОВЕР-сжатый.pdf`. Все 25 страниц отрисованы в исходном разрешении 1920×1080 и сохранены в WebP без потерь. Шрифты, фон, фотографии и композиция сохраняются как в PDF; для кнопок добавлены интерактивные области. Полный текст страниц доступен программам чтения с экрана. Идентификаторы, подписи и зоны кнопок находятся в `src/screens.ts`.

Переход происходит при первом нажатии без ожидания сети: в приложение включены лёгкие копии всех 25 экранов размером 960×540 (`src/transition-previews.json`). Затем изображение текущего экрана заменяется исходным без потерь. При обрыве соединения лёгкая копия и кнопки продолжают работать. Полные изображения хранятся в памяти максимум для четырёх экранов. После изменения изображений копии обновляются командой `python scripts/build_transition_previews.py`; импорт PDF выполняет это автоматически. Тесты проверяют навигацию при недоступности полных изображений и защиту от запоздавших ответов.

Повторная подготовка изображений из того же PDF (для этого нужны PyMuPDF и Pillow):

```sh
python scripts/import_artwork.py /path/to/ЗАБЕЙ-КОВЕР-сжатый.pdf
```

Числа в именах файлов — внутренние идентификаторы, а не номера страниц; соответствие задаётся в этом скрипте. Исходный файл с рецептами сохранён без изменений и в сайт не включён.

По окончательному уточнению автора подключены все шесть кнопок общего ковра из нового PDF. По кнопке «Выездной интерактив» на главной открывается выбор трёх форматов; из «О нас» — общий ковёр, согласно карте. Цепочка `timing → four-hours → booking` и галереи переключаются нажатием справа. Одиночные конечные экраны не перелистываются. Кнопка «Стоимость» на второй странице подарка для бигбосса открывает его стоимость.

Нажатие справа также открывает «Контакты» после стоимости ковра для бигбосса, мастер-классов в студии и ковров на заказ. После «Мы работаем под ключ» оно открывает «Хотите такой интерактив на своём мероприятии?». Кнопка «Назад» возвращает на экран, с которого выполнен переход.

На вертикальном телефоне горизонтальный макет масштабируется целиком, с полями сверху и снизу. Это сохраняет оформление без перекомпоновки, но уменьшает размер текста и кнопок; горизонтальная ориентация использует экран эффективнее.
