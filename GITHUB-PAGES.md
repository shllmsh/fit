# Публикация сайта «Забей ковёр»

Готовая сборка находится в папке `docs` ветки `codex/zabey-kover-preview`.

1. Откройте https://github.com/shllmsh/fit/settings/pages.
2. В разделе Build and deployment установите Source: Deploy from a branch.
3. Выберите Branch: codex/zabey-kover-preview и папку /docs.
4. Нажмите Save.
5. Дождитесь завершения публикации; появится кнопка Visit site.

Ожидаемый адрес после успешной публикации: https://shllmsh.github.io/fit/

Включение GitHub Pages публикует сайт; загрузка этих файлов в ветку сама по себе Pages не включает. На бесплатном тарифе Pages доступен для публичных репозиториев.

Сборка подготовлена с базовым путём /fit/, включает 25 экранов и последние четыре перехода справа. `.nojekyll` отключает обработку статических файлов Jekyll. Сборка проверена по этому же пути на компьютере и телефоне.

Этот адрес можно указать в iframe в HTML-блоке T123 на Tilda после успешной публикации.
